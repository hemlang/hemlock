# Hemlock formal verification proof manifest.
#
# Columns (|-separated):
#   name      unique proof id
#   expect    pass | fail | skip
#             fail = a property that knowingly does not hold (README "Findings");
#             skip = a known coverage gap: `name|skip|reason`, printed on every run
#   tool      cbmc | tlc
#   target    cbmc: harness file in cbmc/harnesses; tlc: config in tla/
#   sources   cbmc: space-separated sources (repo-relative), or - for none;
#             tlc: module
#   flags     extra tool flags (cbmc: -D..., --unwind N, ...); the token
#             @bitwuzla selects the Bitwuzla SMT backend for that proof;
#             @mutant=NAME (tlc) checks tla/mutants/NAME.mut planted into
#             the model instead of the model itself;
#             @pairs expands the line into one proof per integer type pair
#             (name_<lt>_<rt>, e.g. rt_mul_i32_u8); @litpairs / @lits into
#             one per pair of literal classes / per class of the folding
#             proofs (name_<l>_<r> / name_<l>, classes i32 i64 u64)
#
# A proof whose verdict differs from `expect` fails the run, so fixing a
# known defect means flipping its line to `pass` in the same change.
